# IBDAA Atelier POS

New ASP.NET Core 8 tailoring shop management and point-of-sale application.

- Requirements: [SRS](docs/IBDAA-Atelier-SRS-2026-11-10.md)
- Active development: `development` branch
- Database: SQL Server, numeric identity primary keys only
- Existing live website: https://ibdaaatelier.com/ (read-only source for future catalogue import)

The legacy Mashgal Tailoring repository is a reference only. This project does not include its workshop payroll, piece-rate salary, or multi-branch features.

**Status:** Initial repository. The working app is developed and reviewed on `development`.
